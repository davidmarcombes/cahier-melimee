title: "Trouve la règle"
questions:
  - text: "7 ; 15 ; 31 ; 63 ; … Quel est le nombre suivant ?"
    answer: "127"
  - text: "80 ; 85 ; 83 ; 88 ; 86 ; 91 ; … Quel est le nombre suivant ?"
    answer: "89"
  - text: "1 ; 2 ; 6 ; 7 ; 11 ; 12 ; … Quel est le nombre suivant ?"
    answer: "16"
---

Cherche ce qui permet de passer d'un nombre au suivant. La règle peut alterner deux opérations.
