# Couverture du programme

Généré par `npm run coverage:programme` le 2026-11-14. Ne pas éditer : corriger le rattachement dans `docs/programme-map.yaml`.

Un item du programme (`docs/maths_<niveau>.md`) est **couvert** quand au moins une série de son niveau y est rattachée. Le rattachement est automatique (similarité de texte), corrigé à la main dans `docs/programme-map.yaml` : un item couvert peut l’être mal, à vérifier avant de s’y fier pour une décision fine.

Légende : 🟢 ≥ 75 % des items couverts · 🟡 ≥ 50 % · 🟠 > 0 · 🔴 aucun. Cellule = items couverts / items (séries rattachées).
