# Eleventy Build Pipeline

## Overview

The site uses Eleventy v3.1.x (`.eleventy.js`) as the static site generator. Key responsibilities:

- **Collections:** `exercices` (static series) and `applications` (generated series)
- **Filters:** `seriesPayload`, `seriesListPayload`, `extractTypes`, `renderMath`, custom date/sort filters
- **Shortcodes:** `image` (responsive AVIF/WebP via `@11ty/eleventy-img`)
- **Transforms:** `htmlmin` (production HTML minification), `sizeReport` (page size tracking)
- **Virtual templates:** `sitemap.xml`
- **Data formats:** YAML support via `js-yaml`
- **Markdown:** `markdown-it` with MathML LaTeX plugin (`@peaceroad/markdown-it-math-tex-to-mathml`)

## seriesPayload Filter

The `seriesPayload` filter converts exercise front-matter into a JSON array for the Alpine.js `seriesPlayer`. Key behaviors:

- Extracts only the fields needed per exercise type (keeps payload minimal)
- Applies `renderShorthands()` for inline HTML notation (e.g., `&frac(1,2)`)
- Handles `gen: file` SVG embedding: reads `_includes/svg/<name>` at build time, converts to `gen: embedSvg, par: { svg: "..." }`
- Contains a build-time duplicate of `slicedPieSvg` for pre-rendering fraction visuals
- Escapes apostrophes in JSON (`'` → `\u0027`) for safe embedding in single-quoted HTML attributes
