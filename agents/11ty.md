# Eleventy Build Pipeline

## Overview

The site uses Eleventy v3.1.x (`.eleventy.js`) as the static site generator. Key responsibilities:

- **Collections:** `exercices`, `applications`, `defis`, `seriesMeta`, `defisMeta`
- **Filters:** `seriesPayload`, `csvPayload`, `extractTypes`, `renderMath`, custom date/sort filters
- **Shortcodes:** `image` (responsive AVIF/WebP via `@11ty/eleventy-img`)
- **Transforms:** `htmlmin` (production HTML minification), `sizeReport` (page size tracking)
- **Virtual templates:** `sitemap.xml`
- **Data formats:** YAML support via `js-yaml`
- **Markdown:** `markdown-it` with MathML LaTeX plugin (`@peaceroad/markdown-it-math-tex-to-mathml`)

## seriesPayload Filter

The `seriesPayload` filter converts exercise front-matter into a JSON array for the Alpine.js `seriesPlayer`. Key behaviors:

- Extracts only the fields needed per exercise type (keeps payload minimal)
- Applies `renderShorthands()` for inline HTML notation (e.g., `&frac(1,2)`)
- Handles `gen: file` SVG embedding: reads `_includes/svg/<name>` at build time, converts to `gen: embedSvg, par: { svg: "..." }`
- Contains a build-time duplicate of `slicedPieSvg` for pre-rendering fraction visuals
- Escapes apostrophes in JSON (`'` → `\u0027`) for safe embedding in single-quoted HTML attributes

## Collections

| Collection | Source | Description |
|------------|--------|-------------|
| `exercices` | `src/fr/exercices/**/*.md` | All static exercise files |
| `applications` | tagged `applications` | Generated exercise series |
| `defis` | `src/fr/defis/**/*.md` | All timed challenge exercise files |
| `seriesMeta` | Scans `exercices/` + `applications/` index.yaml | Structured metadata: id, level, topic, difficulty, folder |
| `defisMeta` | Scans `defis/` index.yaml | Same as seriesMeta + `duration` (seconds); folder code `'d'` |

### csvPayload Filter

The `csvPayload` filter serializes `seriesMeta` + `defisMeta` into `/fr/exercices/data.csv` (loaded at runtime by the exercise listing page). Format: `id,l,s,t,title,d,f` where:
- `l` = level code (1=CP … 5=CM2)
- `s` = subject initial (M for maths)
- `t` = subtopic slug
- `d` = difficulty code (1=facile, 2=moyen, 3=difficile)
- `f` = folder code (`e`=exercices, `a`=applications, `d`=defis)

Called as: `collections.seriesMeta | csvPayload(collections.defisMeta)`
